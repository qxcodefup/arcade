# MMC de vários Números

## Contexto

Implemente uma função `mmc(numbers []int) int` que receba um vetor de inteiros e retorne o MMC dos números.

### Entrada

* Linha 1: Um número N (N < 50)
* Linha 2: N números inteiros.

### Saída

* O mmc dos N numeros.
