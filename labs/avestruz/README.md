# Avestruz com Alcaparras - ignorar case

![_](assets/cover.jpg)

Conte quantas vezes o caractere aparece na frase ignorando case.

### Entrada

* Uma frase de até 100 caracteres e uma letra.

### Saída

* O número de vezes que a letra aparece na frase.
