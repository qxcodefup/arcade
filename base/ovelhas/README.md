# Contando Ovelhas

![_](assets/cover.png)

Joãozinho está com insônia e decide contar ovelhas para tentar dormir. Como ele quer ter certeza que está contando corretamente, ele te pediu um programa que mostre para cada ovelha contada.


### Entrada

- Um número inteiro **N** de ovelhas a serem contadas.

### Saída

- Imprima **N** linhas:
  - Para primeira ovelha, imprima "1 ovelha"
  - Para as demais, imprima "x ovelhas" onde x é o número de ovelhas contadas até o momento.

### Limites

1 <= N <= 100.
